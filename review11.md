## 3. Доработка индивидуального проекта

В приложении `debts` создана форма `DebtFilterForm` на основе `forms.Form`. Она принимает поиск по студенту или дисциплине, идентификаторы связанных объектов, диапазон дат, состояние и сортировку. Форма проверяет тип идентификаторов, формат дат и порядок границ диапазона. Представление строит ORM-запрос из проверенных значений, а ссылки пагинации сохраняют введённые параметры. Ошибки фильтра отображаются на странице списка.

Для создания и редактирования задолженности создана `DebtForm` на основе `ModelForm` с ограниченным набором полей, русскими подписями, подсказками и полем выбора даты. Сервер отклоняет будущую дату и повторную открытую задолженность одного студента по одной дисциплине. При редактировании текущая запись исключается из проверки на дубликат. Закрытые задолженности не блокируют создание новой открытой записи для той же пары. Ошибки полей и общая ошибка дубликата выводятся в форме; запись сохраняется только после успешной проверки.

Для закрытия задолженности добавлено отдельное действие с запросом `POST` и CSRF-токеном. После закрытия запись остаётся в истории, но перестаёт считаться открытой. При обращении к отсутствующей задолженности возвращается 404. Шаблоны списка и карточки адаптированы к формам; общая структура сайта сохранена. Загрузка изображений не добавлялась: у сущностей DebtTrack нет подходящего изображения, а этот пункт задания предусмотрен только при наличии такого сценария. Порядок работы с формами описан в `README.md`.
