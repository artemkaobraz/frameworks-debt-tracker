# DebtTrack — учёт академических задолженностей

## Назначение

DebtTrack — консольная программа для учёта студентов, задолженностей и пересдач.

## Возможности

- добавление студентов и задолженностей;
- поиск студентов по ФИО;
- проверка и закрытие задолженностей;
- фильтрация и сортировка студентов;
- подсчёт задолженностей и пересдач;
- добавление и отмена пересдач.

## Структура проекта

- `main.py` — запуск программы и меню;
- `students.py` — работа со студентами;
- `debts.py` — работа с задолженностями;
- `retakes.py` — работа с пересдачами;
- `storage.py` — загрузка и сохранение данных;
- `utils.py` — проверка пользовательского ввода;
- `data/` — JSON-файлы с данными;
- `tests/` — тесты программы.

Данные хранятся в словарях и списках и сохраняются в JSON-файлы в папке
`data`.

## Запуск

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск программы:

```bash
python main.py
```

Запуск тестов:

```bash
pytest
```

Проверка кода:

```bash
flake8 .
```
