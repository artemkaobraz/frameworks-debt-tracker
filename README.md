# DebtTrack

DebtTrack — учебное приложение для учёта студентов, дисциплин,
академических задолженностей и пересдач. Оно включает консольную версию с
JSON-хранилищем и read-only веб-интерфейс на Django 5.2. Веб-интерфейс читает
данные из SQLite напрямую через стандартный модуль `sqlite3`, без Django ORM.

## Возможности

Консольное приложение позволяет работать со студентами, дисциплинами,
задолженностями и пересдачами. Оно продолжает загружать и сохранять JSON-файлы.

| Страница | URL | Назначение |
|---|---|---|
| Главная | `/` | Описание приложения и навигация |
| Студенты | `/students/` | Студенты и число активных задолженностей |
| Студент | `/students/<student_id>/` | Данные и задолженности студента |
| Без задолженностей | `/students/clean/` | Студенты без активных задолженностей |
| Задолженности | `/debts/` | Задолженности со студентами и дисциплинами |
| Задолженность | `/debts/<debt_id>/` | Подробные данные задолженности |
| Статистика | `/debts/statistics/` | Активные задолженности по студентам |
| Дисциплины | `/disciplines/` | Список дисциплин |

Отсутствующие объекты и неизвестные адреса возвращают HTTP 404.

## База данных

Рабочая база находится в `data/debt_track.sqlite`. В ней созданы три таблицы:

- `students`: первичный ключ `id`, ФИО, группа и номер зачётной книжки;
- `disciplines`: первичный ключ `id`, название, преподаватель и семестр;
- `debts`: первичный ключ `id`, дата, признак закрытия и внешние ключи
  `student_id` и `discipline_id`.

Все ключи имеют тип `INTEGER`. Внешние ключи таблицы `debts` ссылаются на
студентов и дисциплины. Для признака `is_closed` используются значения 0 и 1.

Файл `sql/schema.sql` содержит схему, а `sql/queries.sql` — 12 запросов:
простые выборки, фильтрацию `WHERE`, соединения `JOIN`, агрегаты, группировку
`GROUP BY`, подзапрос `NOT IN` и условие `HAVING`.

Модуль `db/database.py` создаёт соединение с абсолютным путём к базе, включает
проверку внешних ключей и настраивает строки результата `sqlite3.Row`.
Модуль `db/import_json.py` создаёт схему и переносит исходные данные из JSON.
Импорт можно безопасно запускать повторно:

```bash
python -m db.import_json
```

В исходном наборе дисциплины записаны внутри задолженностей и пересдач. При
импорте они извлекаются теми же правилами совместимости, что использует
консольное приложение. JSON-файлы остаются источником данных консольной версии
и повторного наполнения SQLite.

## Шаблоны и статические файлы

Общий каркас расположен в `templates/base.html`, а навигация — в
`templates/includes/navigation.html`. Страницы приложений наследуют базовый
шаблон через `{% extends %}` и подключают повторяемые фрагменты через
`{% include %}`. Именованные маршруты формируются тегом `{% url %}`.

Стили и JavaScript находятся в `homepage/static/homepage/`. Интерфейс использует
простую текстовую вёрстку, а скрипт выводит текущий год в подвале.

## Структура проекта

```text
frameworks-debt-tracker/
├── data/
│   ├── debt_track.sqlite        # база веб-интерфейса
│   └── *.json                   # данные консольной версии и импорта
├── db/
│   ├── database.py              # подключение к SQLite
│   └── import_json.py           # повторяемый импорт JSON
├── sql/
│   ├── schema.sql               # схема базы
│   └── queries.sql              # учебные SQL-запросы
├── debtly/                      # настройки Django
├── debts/                       # представления и шаблоны задолженностей
├── homepage/                    # главная, дисциплины и статика
├── students/                    # представления и шаблоны студентов
├── templates/                   # базовый шаблон и навигация
├── models/                      # классы предметной области
├── tests/                       # автоматические тесты
├── main.py                      # консольное приложение
├── manage.py                    # управление Django
└── storage.py                   # JSON-хранилище
```

## Установка и запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m db.import_json
python manage.py runserver
```

Сайт доступен по адресу `http://127.0.0.1:8000/`. Консольная версия запускается
командой `python main.py`.
