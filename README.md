# DebtTrack — учёт академических задолженностей

DebtTrack — консольная программа для учёта студентов, дисциплин,
академических задолженностей и пересдач

## Возможности

- добавление и поиск студентов;
- добавление дисциплин;
- создание и закрытие задолженностей;
- поиск должников по дисциплине;
- сортировка студентов по количеству задолженностей;
- добавление и отмена пересдач;
- загрузка и сохранение данных в JSON;
- обработка некорректного ввода и ошибок файлов.

## Классы

### `Student`

Студент.

- атрибуты: `id`, `name`, `group_number`, `record_book`;
- `__str__()` — возвращает ФИО и группу;
- `from_data()` — создаёт объект из словаря;
- `to_data()` — преобразует объект в словарь.

### `Discipline`

Учебная дисциплина.

- атрибуты: `id`, `name`, `teacher`, `semester`;
- `__str__()` — возвращает название дисциплины;
- `from_data()` — создаёт объект из словаря;
- `to_data()` — преобразует объект в словарь.

### `Debt`

Академическая задолженность.

- атрибуты: `id`, `student`, `discipline`, `date_created`, `is_closed`,
  `closed_at`;
- `close()` — закрывает задолженность и сохраняет дату закрытия;
- `__str__()` — возвращает студента, дисциплину и статус;
- `from_data()` — создаёт объект и восстанавливает его связи;
- `to_data()` — преобразует объект в словарь для JSON.

Повторное закрытие задолженности вызывает `ValueError`.

### `Retake`

Пересдача по задолженности.

- атрибуты: `id`, `debt`, `retake_date`, `result`;
- `__str__()` — возвращает студента, дисциплину и дату пересдачи;
- `from_data()` — создаёт объект и восстанавливает связь с задолженностью;
- `to_data()` — преобразует объект в словарь для JSON.

## Связи объектов

Коллекции содержат объекты: `list[Student]`, `list[Discipline]`,
`list[Debt]` и `list[Retake]`.

Объект `Debt` хранит ссылки на `Student` и `Discipline`, поэтому связанные
данные доступны как `debt.student.name` и `debt.discipline.name`. Объект
`Retake` хранит ссылку на `Debt`; например, идентификатор задолженности
доступен как `retake.debt.id`.

## Структура проекта

```text
frameworks-debt-tracker/
├── data/
│   ├── students.json
│   ├── disciplines.json
│   ├── debts.json
│   └── retakes.json
├── models/
│   ├── students.py
│   ├── disciplines.py
│   ├── debts.py
│   └── retakes.py
├── tests/
├── main.py
├── storage.py
├── utils.py
└── requirements.txt
```

- `main.py` — меню и запуск программы;
- `models/students.py` — класс и операции со студентами;
- `models/disciplines.py` — класс и операции с дисциплинами;
- `models/debts.py` — класс и операции с задолженностями;
- `models/retakes.py` — класс и операции с пересдачами;
- `storage.py` — преобразование объектов и работа с JSON;
- `utils.py` — проверка пользовательского ввода;
- `tests/` — тесты проекта.

## Хранение данных

При сохранении объекты преобразуются в словари. Связи записываются через
идентификаторы:

- задолженность содержит `student_id` и `discipline_id`;
- пересдача содержит `debt_id`.

Файлы `students.json`, `disciplines.json`, `debts.json` и `retakes.json`
располагаются в каталоге `data`.

## Установка и запуск

Создание и активация виртуального окружения:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установка зависимостей:

```bash
python -m pip install -r requirements.txt
```

Запуск программы:

```bash
python main.py
```

## Проверка

Запуск всех тестов с подробным выводом:

```bash
pytest -v
```

Проверка стиля кода:

flake8 .
