# DebtTrack — учёт академических задолженностей

DebtTrack — учебное приложение для учёта студентов, дисциплин,
академических задолженностей и пересдач. Проект включает консольное приложение
и read-only веб-интерфейс на Django 5.2. Данные хранятся в JSON; Django ORM,
веб-формы и авторизация пока не используются.

## Возможности

Консольное приложение поддерживает добавление и поиск студентов, работу с
дисциплинами, создание и закрытие задолженностей, назначение пересдач, загрузку
и сохранение связанных объектов.

Веб-интерфейс предоставляет следующие страницы:

| Страница | URL | Назначение |
|---|---|---|
| Главная | `/` | Описание приложения и навигация |
| Студенты | `/students/` | Список студентов и число активных долгов |
| Студент | `/students/<student_id>/` | Данные и задолженности студента |
| Задолженности | `/debts/` | Список задолженностей и статусы |
| Задолженность | `/debts/<debt_id>/` | Подробные данные задолженности |
| Дисциплины | `/disciplines/` | Список дисциплин |

Отсутствующие объекты и неизвестные адреса возвращают HTTP 404.

## Шаблоны Django

Общий каркас расположен в `templates/base.html`. Он подключает статические
файлы, текстовый бренд, навигацию из `templates/includes/navigation.html`, область
содержимого и подвал. Шаблоны приложений размещены внутри самих приложений:

- `homepage/templates/homepage/` — главная, дисциплины и страница 404;
- `students/templates/students/` — список и страница студента;
- `debts/templates/debts/` — список и страница задолженности.

Страницы наследуют общий каркас через `{% extends %}` и заполняют блоки
`title` и `content`. Повторяемые фрагменты подключаются через `{% include %}`:
карточка студента, статус задолженности и навигация. Для внутренних ссылок
используются `{% url %}` и пространства имён `homepage`, `students`, `debts`.
Количество элементов выводится фильтром `length`, а резервные подписи —
фильтром `default`.

Представления отвечают только за подготовку контекста и вызов `render()`.
Контекст списков содержит коллекции студентов или задолженностей, а подробных
страниц — выбранный объект и связанные данные. Число активных задолженностей
вычисляется в Python и передаётся шаблону отдельно.

## Статические файлы

Статика приложения находится в `homepage/static/homepage/`:

- `css/style.css` — минималистичное оформление страниц;
- `js/main.js` — вывод текущего года в подвале;

Название DebtTrack в шапке оформлено как текстовый заголовок и остаётся
доступным даже без загрузки изображений.

## Структура проекта

```text
frameworks-debt-tracker/
├── data/                         # JSON-данные
├── debtly/                       # настройки и маршрутизация Django
├── debts/
│   └── templates/debts/          # страницы и фрагменты задолженностей
├── homepage/
│   ├── static/homepage/          # CSS и JavaScript
│   └── templates/homepage/       # главная, дисциплины и 404
├── models/                       # классы предметной области
├── students/
│   └── templates/students/       # страницы и фрагменты студентов
├── templates/
│   ├── base.html                 # общий каркас
│   └── includes/navigation.html  # общая навигация
├── tests/                        # автоматические тесты
├── main.py                       # консольное приложение
├── manage.py                     # управление Django
├── storage.py                    # загрузка и сохранение JSON
└── requirements.txt
```

## Установка и запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python manage.py runserver
```

После запуска сайт доступен по адресу `http://127.0.0.1:8000/`.
Консольная версия запускается командой `python main.py`.
