# DebtTrack — учёт академических задолженностей

DebtTrack — учебное приложение для учёта студентов, дисциплин,
академических задолженностей и пересдач. Работать с данными можно через
консольное приложение или read-only веб-интерфейс на Django 5.2.

## Возможности

Консольное приложение поддерживает добавление и поиск студентов, работу с
дисциплинами, создание и закрытие задолженностей, назначение пересдач, а также
загрузку и сохранение связанных объектов в JSON.

Веб-интерфейс предназначен только для просмотра данных:

| Страница | URL | Назначение |
|---|---|---|
| Главная | `/` | Описание приложения и навигация |
| Студенты | `/students/` | Список студентов и число активных долгов |
| Студент | `/students/<student_id>/` | Карточка и задолженности студента |
| Задолженности | `/debts/` | Список задолженностей и их статусы |
| Задолженность | `/debts/<debt_id>/` | Подробная карточка задолженности |
| Дисциплины | `/disciplines/` | Список дисциплин |

Для неизвестных адресов настроена собственная страница ошибки 404. Для
проверки её оформления следует временно установить `DEBUG = False` в
`debtly/settings.py`, а после проверки вернуть значение `True`.

## Устройство веб-приложения

- `homepage.views.index()` выводит главную страницу;
- `homepage.views.disciplines()` выводит дисциплины;
- `homepage.views.page_not_found()` формирует страницу ошибки 404;
- `students.views.students()` и `student_detail()` выводят список и карточку;
- `debts.views.debts()` и `debt_detail()` выводят список и карточку долга.

Представления передают данные в Django-шаблоны из каталога `templates`.
`base.html` содержит общий каркас, навигацию и минималистичные стили, а шаблоны
разделов наследуют его. Данные загружаются функцией `storage.load_data()` из
каталога `data`, путь к которому строится относительно `BASE_DIR`.

## Структура проекта

```text
frameworks-debt-tracker/
├── data/                 # JSON-данные приложения
├── debtly/               # настройки и корневая маршрутизация Django
├── debts/                # страницы задолженностей
├── homepage/             # главная, дисциплины и общий каркас
├── models/               # классы Student, Discipline, Debt и Retake
├── students/             # страницы студентов
├── templates/            # HTML-шаблоны Django и общий каркас страниц
├── tests/                # тесты предметной модели, хранилища и страниц
├── main.py               # консольное приложение
├── manage.py             # утилита управления Django
├── storage.py            # загрузка и сохранение JSON
├── utils.py
└── requirements.txt
```

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Запуск

Веб-приложение:

```bash
python manage.py migrate
python manage.py runserver
```

После запуска главная страница доступна по адресу
`http://127.0.0.1:8000/`.

Консольное приложение запускается отдельно:

```bash
python main.py
```
