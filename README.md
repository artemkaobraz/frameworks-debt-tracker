# DebtTrack — Система учёта академической задолженности (Python)

## Название проекта
**DebtTrack** — приложение для контроля академических задолженностей студентов

## Назначение
Приложение предназначено для ведения учёта студентов, имеющих задолженности по дисциплинам, отслеживания сроков пересдач и формирования сводной информации для сотрудников деканата и преподавателей.

## Целевая аудитория
- Работники деканата
- Преподаватели и кураторы групп
- Студенты
- Администрация учебного заведения

## Описание предметной области
В учебном процессе студент может не сдать зачёт или экзамен в установленный срок — в этом случае у него образуется академическая задолженность по конкретной дисциплине. До момента ликвидации задолженности студент обязан пройти пересдачу. Приложение систематизирует сведения о возникших задолженностях, фиксирует факты пересдач и позволяет оперативно получать аналитику по группам и дисциплинам.

## Основные сущности (Python-классы)
- `Group` — учебная группа (название, курс, список студентов)
- `Student` — студент (ФИО, группа, номер зачётной книжки)
- `Discipline` — дисциплина (название, преподаватель, семестр)
- `Debt` — задолженность (студент, дисциплина, дата возникновения, текущий статус)
- `Retake` — пересдача (дата проведения, результат, преподаватель)

## Основные функции

- Формирование списка студентов, имеющих задолженности по заданной дисциплине
- Подсчёт общего числа задолженностей у конкретного студента
- Выявление студентов, у которых более одной задолженности
- Фиксация факта пересдачи с обновлением статуса задолженности
- Проверка наличия задолженностей у студента на текущий момент
